# Contributing to IE Platform Documentation

This repository is the single source of truth for IE Platform documentation. Contributions should improve clarity, maintainability, and long-term usefulness for engineering, product, security, and operations teams.

## Contribution Principles

- Keep content accurate, concise, and structured.
- Use document IDs and a consistent naming convention.
- Prefer evidence-backed decisions and linked references.
- Update related documents when making changes that affect architecture, APIs, or workflows.

## Workflow

1. Create or update a document in the appropriate section.
2. Use the relevant template from the templates directory.
3. Ensure front matter is present for template-based documents.
4. Submit a pull request with a clear summary and rationale.

## Review Expectations

- Product and engineering changes require architecture review.
- Security changes require security review.
- API or database changes require relevant owner approval.

## Pull Request Checklist

- [ ] Content follows the repository style.
- [ ] Document metadata is complete.
- [ ] Related links and references were checked.
- [ ] Changes are scoped and easy to review.

## Communication

For questions, use issues or discussions in the repository. For urgent security matters, refer to the security policy.
