# Templates

## Purpose

This folder provides reusable templates for architecture, product, API, database, design, testing, and release documentation.

## Contents

- ADR
- PRD
- FRS
- Database table specs
- API specs
- Screen specs
- Component specs
- Test cases
- Release notes
- Sequence and architecture diagrams

## Naming Convention

Use the canonical template names and update the front matter for new documents.

## Ownership

The Documentation Guild maintains these templates.

## Review Process

Review templates when structural or governance standards change.
