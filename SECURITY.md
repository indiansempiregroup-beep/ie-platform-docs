# Security Policy

The IE Platform documentation repository follows secure contribution and publishing practices.

## Reporting a Vulnerability

Please report suspected vulnerabilities through the private security contact designated by the organization. Do not open public issues for security concerns.

## Response Expectations

- Acknowledgement within a reasonable timeframe.
- Investigation and remediation planning.
- Clear communication of status and mitigation steps.

## Handling Expectations

- Do not expose sensitive data in issues or pull requests.
- Keep credentials and internal tokens out of repository content.
