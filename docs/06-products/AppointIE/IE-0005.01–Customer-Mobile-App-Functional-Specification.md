This document defines every functional requirement of the AppointIE Customer Mobile Application\.

It serves as the implementation reference for:

- UI/UX Design
- React Native Development
- Backend API Integration
- QA Testing
- AI\-assisted Development

# <a id="_8v01t6yfqknd"></a>__2\. Mobile Application Overview__

The Customer Mobile App enables customers to:

- Register
- Sign in
- Browse businesses
- Browse services
- View pricing
- Book appointments
- Manage appointments
- Receive notifications
- Submit reviews
- Manage profile information

The application communicates only through the IE Platform REST API\.

# <a id="_9efvpsjo3jqs"></a>__8\. Global Business Rules__

GBR\-001

A customer may only access data belonging to the selected business\.

GBR\-002

Bookings cannot be created outside configured business hours\.

GBR\-003

Bookings cannot overlap for the assigned staff member\.

GBR\-004

Completed appointments cannot be modified\.

GBR\-005

Only completed appointments may receive reviews\.

GBR\-006

Every booking generates an audit log\.

# <a id="_9flmlv4rsdg1"></a>__9\. Offline Behaviour__

# <a id="_9iiu0z2exi8i"></a>__12\. Acceptance Criteria__

Example — Customer Booking

Given

The customer is authenticated\.

And

The selected service is available\.

When

The customer selects a valid time slot and confirms the booking\.

Then

The booking is created with status "Pending"\.

The business receives a notification\.

The customer receives a confirmation message\.

The booking appears in "My Bookings"\.

An audit log entry is created\.
