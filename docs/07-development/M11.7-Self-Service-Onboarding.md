# M11.7 — Self-Service Business Onboarding

Architecture notes and developer guide for the M11.7 milestone.

See the implementation repository for source:

- `ie-platform/docs/M11.7-Self-Service-Onboarding.md`
- `ie-platform/web/src/features/onboarding/`
- `ie-platform/web/src/features/public/`

## Scope delivered

- Public marketing pages (Home, Features, Pricing foundation, About, Contact, Privacy, Terms, FAQ, 404)
- Authentication UI (sign in, forgot/reset password, email verification, resend)
- Six-step registration wizard with Zod + React Hook Form
- Client-side provisioning orchestration via shared SDK
- Getting started checklist on first dashboard visit
- Workspace summary card (business, status, product, plan placeholder, currency)
- Currency formatting from business profile (no hardcoded INR)
- Billing UI foundation only (no payments)
