## 1. Purpose

This document maps IE Platform design tokens across the design and implementation layers. It provides the baseline values needed for Figma variables, CSS variables, web theme configuration, and React Native theme definitions.

## 2. Token Mapping Model

The mapping follows a single-source-of-truth model:

- Design tools consume semantic tokens.
- Web implementation consumes CSS variables.
- Mobile implementation consumes React Native theme tokens.
- Product-specific theming remains constrained to approved token surfaces.

## 4. Platform Mapping

### Web Theme

- Use CSS variables for theming and component styling.
- Ensure theme values are available at the app shell level.

### React Native Theme

- Map semantic tokens to theme objects and component styles.
- Support light and dark mode through the same token set.

### Figma Variables

- Store tokens as variables grouped by category for discoverability.
- Link the variables to component libraries for consistent usage.

## Glossary

| Term | Definition |
| --- | --- |
| Token | A reusable value that governs appearance and behavior |
| Theme | A named configuration that applies a token set to a product surface |
