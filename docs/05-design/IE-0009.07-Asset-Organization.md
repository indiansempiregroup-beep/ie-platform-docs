## 1. Purpose

This document defines how design assets should be organized for the IE Platform. The goal is to make assets easy to find, reuse, and hand off to implementation teams without introducing inconsistency.

## 2. Asset Categories

| Category | Examples |
| --- | --- |
| Icons | Navigation, status, action icons |
| Illustrations | Empty states, onboarding, feature explainers |
| Images | Photos, screenshots, product visuals |
| Logos | Tenant and platform branding |
| Animations | Micro-interactions, loading states, motion prototypes |
| Brand Assets | Color kits, type samples, assets for white-label adaptation |

## 3. Folder Structure

```text
assets/
  icons/
  illustrations/
  images/
  logos/
  animations/
  brand/
```

## 4. Export Rules

- Use SVG for icons and simple vector assets.
- Use PNG only where raster export is required.
- Keep file names descriptive and consistent with component names.
- Avoid embedding unnecessary metadata or duplicate variants.

## Glossary

| Term | Definition |
| --- | --- |
| Asset | A reusable design resource used in product experiences |
| Brand asset | A visual resource used to support white-label presentation |
