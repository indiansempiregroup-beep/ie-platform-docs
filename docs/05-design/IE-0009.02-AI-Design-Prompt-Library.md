## 1. Purpose

This library provides production-ready prompts for generating UI and experience concepts in Figma AI, Lovable, and future AI design platforms. Each prompt is grounded in the IE Platform architecture, the AppointIE product requirements, and the existing design system.

## 2. Prompt Strategy

Each prompt should:

- Reference the product surface and user role
- Invoke the approved design system and token language
- Preserve accessibility, responsive behavior, and clarity
- Avoid introducing unsupported visual or architectural patterns

## 3. Prompt Catalog

### Customer App

Prompt: Create a polished mobile booking experience for AppointIE customers. Use a mobile-first layout, clear service discovery, calendar-based booking, confirmation states, and accessible forms. Support light and dark modes, maintain the IE Platform design system, and use semantic components.

### Operations Dashboard

Prompt: Design a high-clarity operations dashboard for a business owner. Show booking queues, calendar views, service controls, customer and staff management, and notification center patterns. Use strong information hierarchy, responsive panels, and accessible data tables.

### Business Intelligence Dashboard

Prompt: Create an executive analytics surface for AppointIE. Present KPIs, revenue trends, growth metrics, bookings, and report exports in a clean, dashboard-driven layout. Prioritize scannability, chart clarity, filter behavior, and accessibility.

### Platform Admin

Prompt: Create a platform administration workspace for tenant and subscription operations. Include tenant overview, branding controls, monitoring, audits, and platform settings. Keep the experience structured, secure, and role-aware.

### Authentication

Prompt: Design a clean authentication experience with login, registration, OTP verification, password reset, and secure error states. The experience should feel trustworthy, concise, and highly accessible.

### Booking

Prompt: Design a booking workflow that supports service selection, staff choice, date and time selection, review, confirmation, and reschedule. Optimize for mobile interaction and reduce cognitive load.

### Calendar

Prompt: Create a responsive calendar experience for scheduling and booking management. Support month and week views, availability states, selection interaction, and clear visual hierarchy.

### Reports

Prompt: Design a report experience with filters, date ranges, trend summaries, export actions, and clear table presentations. Use a professional, analytical visual language.

### Analytics

Prompt: Create an analytics experience that surfaces performance insights through charts, summaries, and comparison views. Keep the interface readable, interactive, and accessible across desktop and tablet.

### Settings

Prompt: Design a settings experience for business and user configuration. Include notification preferences, profile preferences, security controls, and state feedback without overwhelming the user.

### Notifications

Prompt: Design a notification center for reminders, booking changes, and system messages. Structure the experience to support quick scanning, clear actions, and accessible feedback.

### Profile

Prompt: Create a profile experience for customers and business users. Include account details, preferences, saved data, and secure update flows with clear validation states.

## 4. Prompt Quality Rules

- Prefer structured prompts with explicit goals, constraints, and requested UI patterns.
- Include the target platform, user role, and required states.
- Request semantic components, accessible patterns, and responsive behavior.
- Ask for consistency with the shared token set and white-label support rules.
