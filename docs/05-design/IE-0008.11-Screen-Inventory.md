## 1. Purpose

This document inventories every screen expected to be designed for the IE Platform before the design system is implemented in Figma. It maps each screen to its purpose, priority, dependencies, and related APIs so that design work can proceed in a structured, traceable manner.

## 2. Inventory Structure

Each screen entry includes:

- Screen ID
- Screen Name
- Purpose
- Priority
- Dependencies
- Related APIs
